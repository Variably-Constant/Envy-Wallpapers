# Wallpapers

Each folder here is one wallpaper, named by its id: its `wallpaper.toml`, a 480 x 270 thumbnail, and its images. See
[CONTRIBUTING.md](../CONTRIBUTING.md) for how to add one and [docs/FORMAT.md](../docs/FORMAT.md) for every key of
`wallpaper.toml`. The publish workflow lists every folder here in the store's catalog; files beside the folders, like this
one, are not listed.
